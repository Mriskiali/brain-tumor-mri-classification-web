# Klasifikasi Tumor Otak dari Citra MRI

Model hybrid Autoencoder + CNN untuk mengklasifikasikan citra MRI otak ke dalam
empat kelas: glioma, meningioma, pituitary, dan non-tumor.

Aplikasi ini adalah alat bantu penelitian dan bukan pengganti diagnosis medis.
